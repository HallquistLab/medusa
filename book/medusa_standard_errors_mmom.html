Propagating BOLD Noise into Trial Standard Errors

How run-level serial covariance travels through deconvolution, epoch demixing, and run-centering into M-MOMS error blocks

Overview: What Exactly Does se_demixed Measure?

When analysts inspect a Step 3 or Step 4 output panel (epochs$panel), every trial-by-parcel-by-lag row carries both a de-mixed neural estimate (decon_demixed) and an analytical standard error (se_demixed). Before using these quantities in multilevel outcome models (Step 5) or measurement-error-corrected connectivity models (Step 6), a foundational question arises:

How do we get an individual standard error for a single trial when that trial was never repeated—and how does se_demixed differ from a mixed-model slope SE or an Empirical-Bayes posterior SD?

In MEDuSA, se_demixed is the conditional measurement-error standard deviation of the linear estimator that maps a noisy BOLD run vector \(y_r\) onto trial \(i\)’s de-mixed readout \(\widehat{z}_{ri} = \theta_{ri} + e_{ri}\). Because continuous deconvolution (\(D_r\)), collateral event subtraction, target-trial demixing, and within-run centering compose into one explicit linear operator \(B_{r,\tau}\), any stationary observation noise covariance \(\operatorname{Cov}(\varepsilon_r) = \sigma_{\text{obs}}^2 \Sigma_{\text{cor}}\) propagates algebraically from acquisition frames to trials:

\[ \underbrace{\sigma_{\text{obs}}^2 \Sigma_{\text{cor}}}_{\text{Run BOLD noise (Steps 1–2)}} \ \longrightarrow\ \underbrace{\widehat{\Omega}_{r,\tau} = \operatorname{Cov}(e_{r,\tau} \mid B_{r,\tau})}_{\text{Centered trial error covariance (Steps 3–4)}} \ \longrightarrow\ \underbrace{s_{ri} = \sqrt{[\widehat{\Omega}_{r,\tau}]_{ii}}}_{\text{`se_demixed`}} \ \longrightarrow\ \underbrace{\Psi_i(s_{S,i}^2),\; c_i}_{\text{M-MOMS error moments (Step 6)}}. \]

NoteCore Methodological Question & Connection to the Pipeline

Why does Step 5 weight outcomes by \((\widehat{\tau}_{\text{eff}}^2 + s_{ri}^2)^{-1}\) (precision_weight_cohort), whereas Step 6 subtracts pure measurement variance \(s_{S,i}^2\) (se_demixed^2) inside \(\Psi_i\)—and why does run-centering introduce a \((1 - 1/m)^{-1}\) finite-sample factor?

This chapter traces the exact variance-propagation chain connecting Steps 1–2, Steps 3–4, and Step 6 (decon_connectivity_repair() / medusa_fit_mmom()).

1. Anchor Run-Level Observation Noise Scale Prior to Trial Regression

For run \(r\) and a single voxel (or parcel stratum), recall the linear neurovascular forward model on retained acquisition frames:

\[ y_r = H_r a_r + Z_r \gamma_r + \varepsilon_r, \qquad \operatorname{Cov}(\varepsilon_r) = \sigma_{\text{obs}}^2 \Sigma_{\text{cor}}, \]

where \(H_r\) is causal Toeplitz convolution with the cross-fitted HRF, \(Z_r\) collects low-frequency drift and nuisance covariates, \(\Sigma_{\text{cor}}\) is the unit-diagonal temporal correlation matrix from Step 1’s two-pass REML \(\text{AR}(p)\) cascade (restricted to unmasked acquisition timestamps \(\Sigma_{\text{AR}}[I_r, I_r]\) whenever motion scrubbing creates gaps), and \(\sigma_{\text{obs}}\) is the marginal observation-noise standard deviation (not the white-noise innovation SD).

Estimating \(\sigma_{\text{obs}}\) accurately requires shielding the scale estimator from true task-evoked BOLD deflections and isolated motion glitches:

  • Primary cross-run estimator (deconvolve_crossrun_hrf(..., scaling = "noise_sd")): Conditions on Step 1’s cross-fitted HRF and Pass-2 \(\text{AR}(p)\) correlation matrix, projects out the event and nuisance subspace in whitened coordinates, computes outlier-trimmed (Winsorized), leverage-standardized GLS innovation scale, and converts innovation scale analytically into stationary marginal observation SD \(\widehat{\sigma}_{\text{obs}}\).
  • Standalone single-run and omitted-event safeguard (deconvolve_reglin()): When cross-run event designs are unavailable or degrees of freedom are low, MEDuSA estimates marginal noise SD from second differences \(d_t = y_t - 2y_{t-1} + y_{t-2}\), which annihilate smooth hemodynamic trends while combining sample SD with zero-centered median absolute deviation (\(\operatorname{MAD}_0\)), normalized analytically by lag-1 and lag-2 autocorrelations \((\widehat{r}_1, \widehat{r}_2)\):

\[ \widehat{\sigma}_{\text{obs}} = \frac{0.5\,\operatorname{SD}(d) + 0.5\,\operatorname{MAD}_0(d)} {\sqrt{6 - 8\widehat{r}_1 + 2\widehat{r}_2}}. \]

Crucially, both estimators determine \(\widehat{\sigma}_{\text{obs}}\) before any behavioral covariate or seed-parcel connectivity hypothesis is tested, avoiding circular variance tuning.

2. Propagate Covariance Through Deconvolution, Demixing, and Run-Centering

Conditioning on the learned HRF, smoothness penalty \(\lambda_v\), adaptive frame weights, nuisance projection, and \(\text{AR}(p)\) parameters, Step 2 deconvolution is an explicit linear map \(\widehat{a}_r = D_r \tilde{y}_{r,o}\). In Step 3 (decon_epoch_regression()), local kernel readout \(S_\tau\), non-target event subtraction, ridge-stabilized target-trial demixing \(W_\tau\), and diagonal gain restoration \(\tilde{G}_\tau\) compose with \(D_r\) into the run’s trial-readout operator \(B_{r,\tau}\). Applying the linear covariance law \(\operatorname{Cov}(Ay) = A\operatorname{Cov}(y)A^\top\) gives the uncentered \(m \times m\) trial error covariance across the \(m\) valid target trials of run \(r\):

\[ \Omega_{r,\tau,\text{raw}} = \sigma_{\text{eff}}^2 \, \widetilde{B}_{r,\tau} \Sigma_{\text{cor}} \widetilde{B}_{r,\tau}^\top, \]

where \(\widetilde{B}_{r,\tau}\) absorbs input run-centering and whitened nuisance projections. In our independent algebraic audit (worked/mmom-check.R), MEDuSA’s factored cascade propagation matches brute-force dense \(\text{AR}(3)\) Toeplitz matrix multiplication to 1.11e-16.

Why run-centering introduces \((1 - 1/m)^{-1}\)

Subtracting the run mean from \(m>1\) trial estimates applies \(Q_m\) to their error vector. Its covariance is exactly \(Q_m\Omega_{r,\tau,\text{raw}}Q_m\). For independent errors of common variance \(\sigma^2\), each diagonal is now \(\sigma^2(1-1/m)\). MEDuSA divides by \(1-1/m\) when reporting per-trial variance on a degrees-of-freedom-adjusted scale. In the general correlated case, the matrix multiplication accounts for how centering changes each diagonal.

\[ Q_m = I_m - \frac{\mathbf{1}_m\mathbf{1}_m^\top}{m}, \qquad \widehat{\Omega}_{r,\tau} = \frac{Q_m \Omega_{r,\tau,\text{raw}} Q_m}{1 - 1/m}, \qquad \boxed{\texttt{se\_demixed}_{ri} = \sqrt{\max\!\bigl(0,\, [\widehat{\Omega}_{r,\tau}]_{ii}\bigr)}}. \]

Why do individual trials within the same run have different values of se_demixed? Three geometric factors enter \([\widehat{\Omega}_{r,\tau}]_{ii}\):

  1. Temporal crowding: Closely spaced trials require stronger off-diagonal demixing weights in \(W_\tau\), amplifying propagated variance relative to well-isolated trials.
  2. Motion-scrubbing shadows: Censored frames inside a trial’s causal HRF window reduce effective BOLD observations supporting that event, selectively elevating its diagonal entry (see Pair 3 in the Visual QC Gallery).
  3. Run boundaries: Trials near scanner shutoff lose late HRF tail samples, increasing uncertainty smoothly before extreme truncation triggers min_bold_coverage NA gating.

Preserving scale equivalence and spatial parcel correlations

When Step 2 standardizes series by \(\widehat{\sigma}_{\text{obs}}\) (scaling = "noise_sd"), setting restore_scale = TRUE in Step 3 multiplies both decon_demixed and se_demixed back by \(\widehat{\sigma}_{\text{obs}}\) so every run of a parcel shares physical BOLD units. More generally, rescaling any neural variable by a constant \(c\) rescales its SE by \(|c|\) and its error variance by \(c^2\).

When voxels are aggregated into anatomical parcels in Step 4 (parcel_groups), summing voxel variances naively would underestimate parcel noise because neighboring voxels share physiological and thermal fluctuations. MEDuSA instead propagates Step 2’s task-free whitened noise_innovations (\(\widetilde{E}_r\)) through each voxel’s operator stratum to compute exact within-parcel spatial noise covariance, while fitting Adaptive-POET and LTZ-gated dynamic covariance regression (shared_error_model and compact Block-PAF list-columns shared_noise_vec / lag_noise_vec; see Step 4 §4.4) for Step 6 cross-parcel shared-error subtraction.

Constructing \(\Psi_i\) and calling medusa_fit_mmom() directly for Behavior ~ Neural

When testing parcel-to-parcel connectivity or PPI (Target ~ Seed * Task), decon_connectivity_repair() builds the \(3 \times 3\) trial error block \(\Psi_i\) automatically:

\[ \Psi_i = s_{S,i}^2 \begin{bmatrix} 1 & 0 & x_i \\ 0 & 0 & 0 \\ x_i & 0 & x_i^2 \end{bmatrix}, \]

capturing both heteroskedastic interaction noise \(x_i^2 s_{S,i}^2\) and the off-diagonal covariance \(x_i s_{S,i}^2\) induced because Seed and Seed:x share the same noisy neural realization \(u_i\).

What if your scientific question instead places deconvolved neural activity on the right-hand side to predict a trial-level behavioral outcome—such as log reaction time, continuous confidence ratings, or drift-diffusion boundary shifts (Behavior ~ Neural + Task)? Because behavioral outcomes do not carry fMRI scanner noise (err_y = 0, err_xy = 0), you can call medusa_fit_mmom() directly per participant using se_demixed^2:

Show supporting code 
library(medusa)
set.seed(20261110)
n <- 300L
theta_neural <- rnorm(n)
task_cov <- rnorm(n)
se_trial <- runif(n, 0.30, 0.70)
trial_df <- data.frame(
  decon_demixed = theta_neural + rnorm(n, sd = se_trial),
  se_demixed    = se_trial,
  task          = task_cov,
  rt_z          = 0.60 * theta_neural + 0.25 * task_cov + rnorm(n, sd = 0.80)
)
X <- cbind(neural = trial_df$decon_demixed, task = trial_df$task)
Psi <- array(0, dim = c(ncol(X), ncol(X), nrow(X)))
Psi[1, 1, ] <- trial_df$se_demixed^2   # neural predictor error variance; task is error-free (0)

fit <- medusa_fit_mmom(
  outcome        = trial_df$rt_z,
  predictors     = X,
  err_x          = Psi,                # q x q x N predictor error covariance array
  err_y          = rep(0, nrow(X)),    # error-free behavioral outcome
  regularization = "step_up"           # M-MOMS conditioning protection
)

4. Scope Conditions and What se_demixed Does Not Capture

  1. Distribution-free second moments vs. plug-in conditioning: Conditional on the linear operator \(B_{r,\tau}\) and noise covariance \(\Sigma_r\), \(\operatorname{Cov}(B_{r,\tau}\varepsilon_r) = B_{r,\tau}\Sigma_r B_{r,\tau}^\top\) holds for any zero-mean noise process with finite variance (Winsorized/MAD scale factors calibrate efficiency under Gaussian innovations). Like REPAIR (Vig & Hallquist, 2026), downstream Step 5–6 estimators treat first-stage se_demixed^2 as known plug-in variances and anchor group uncertainty to between-participant dispersion.
  2. Observation noise vs. unequal source resolution: se_demixed^2 measures random scatter \(B_{r,\tau}\Sigma_r B_{r,\tau}^\top\) around \(\mathbb{E}[\widehat{z} \mid \theta] = K\theta\), not deterministic resolution mismatch \((K - I)\theta\) when strong smoothing or severe HRF mis-specification leaves \(K_S \neq K_T\). How unequal resolution and cross-trial error correlations behave—and how extended measurement models address them—is examined in Latent Connectivity Beyond Per-Trial Disattenuation.
