What Validation Proves—and Building Study-Specific Checks

Synthesizing mechanism benchmarks, the 14-study validation suite, and custom power/calibration simulations on empirical schedules

Overview: Why No Single Simulation Answers Every Empirical Question

Across the stepwise tutorials (Part II), spatial workflows (Part III), and methodological deep dives (Part IV), every core component of medusa is paired with numerical checks and Monte Carlo simulations. A thoughtful investigator or peer reviewer should still ask a sharper meta-question:

Which properties of MEDuSA are guaranteed by linear algebra, which depend on empirical regularity conditions tested in Monte Carlo benchmarks, and how can I verify that my own study’s event schedule, motion censoring, and sample size support calibrated inference before testing substantive hypotheses?

NoteCore Methodological Question & Connection to the Pipeline

Where do general package benchmarks end and study-specific design geometry begin—and how do you turn an empirical events table and valid_rows mask from Step 0 into a custom end-to-end calibration check?

This capstone chapter synthesizes the evidence across all four Part IV deep dives and the 14-Study Validation Suite, then provides a compact R template for study-specific synthetic calibration.

1. Three Distinct Layers of Evidence in medusa

Keeping three levels of validation distinct prevents both over-claiming and unnecessary skepticism:

  1. Exact conditional operator identities (algebraic & numerical checks): Once run \(r\)’s HRF, smoothing parameter \(\lambda_v\), adaptive weights, and noise correlation \(\Sigma_{\text{cor}}\) are fixed, deconvolution (\(D_r\)) and de-mixed epoch readout (\(B_{r,\tau}\)) are deterministic linear maps. Identities such as \(\operatorname{Cov}(B_{r,\tau}\varepsilon_r) = \sigma_{\text{obs}}^2 B_{r,\tau}\Sigma_{\text{cor}}B_{r,\tau}^\top\) (Propagating BOLD Noise into Trial SEs), scale invariance under restore_scale = TRUE, and \(B_g G_g = I\) in full-rank finite bases (Latent Connectivity Beyond Per-Trial Disattenuation) hold to machine precision (\(10^{-13}\text{--}10^{-15}\)). They guarantee that the code computes the exact mathematical quantity promised—conditional on the first-stage operators.
  2. Isolated mechanism stress tests (Part IV deep dives & chapter benchmarks): Each mechanism study varies one realistic threat at a time while holding surrounding structure transparent—such as fast/slow neurovascular dispersion against \(\text{AR}(3)\) noise (Autocorrelation Prewhitening Under Fast-TR Event Designs), censored edge lags and serial trial dependence in medusa_multilag_infer() (Simultaneous Bands Across Lags), or unequal regional smoothing \(K_S \neq K_T\) and small-\(S\) clustering in connectivity (Latent Connectivity Beyond Per-Trial Disattenuation). These isolate why an estimator succeeds or breaks down.
  3. End-to-end pipeline Monte Carlo benchmarks (14-Study Validation Suite): Refits the entire sequence (estimate_crossrun_hrf() \(\to\) deconvolve_crossrun_hrf() \(\to\) decon_epoch_regression() \(\to\) mixed_by() / medusa_multilag_infer() / decon_connectivity_repair()) inside every synthetic cohort, capturing how estimation uncertainty in Step 1 HRF selection and Step 2 GCV/RWLS tuning propagates into final population \(p\)-values and confidence intervals.

3. Building a Study-Specific Calibration on Your Own Schedule

Whenever an empirical study uses a novel multi-phase trial timing, heavy motion scrubbing, or small cohort size, the most informative validation you can run is a synthetic twin of your exact task geometry. Because read_fmriprep_subject() (Step 0) already extracts each participant’s real events table, run lengths, TR, and framewise-displacement valid_rows masks, you can simulate synthetic BOLD directly on top of your actual empirical design in ~35 lines of R—without peeking at real neural associations:

  1. Lock the estimand and multiplicity rule upfront: Prespecify the target condition, peri-event lag(s), covariates, window contrasts, and parcel-family adjustment ("holm" or "BY").
  2. Keep real onset times, durations, and censor masks intact: Use your cohort’s actual events timestamps, reaction-time durations, and valid_rows scrubbing vectors so collinearity between adjacent task phases and run-end/motion truncation match your study verbatim.
  3. Include both an active parcel and a structured null parcel: Generate voxelwise HRF dispersion from hrf_library(), realistic \(\text{AR}(1)\) temporal noise (\(\rho \approx 0.45\text{--}0.60\)), and—if testing Step 6 PPI—shared cross-parcel background innovations.
  4. Refit the full medusa pipeline in every replicate: Run estimate_crossrun_hrf(), deconvolve_crossrun_hrf(), and decon_epoch_regression() from scratch inside the loop rather than freezing oracle HRFs or smoothing parameters.
  5. Audit bias, CI coverage, null false positives, and gating rates together: Check mean(is.na(decon_demixed)), diagnose_crossrun_recovery()$summary$mean_gain, isSingular() rates in mixed_by(), and empirical 95% coverage.
library(medusa)

# Template: Synthetic twin check on one participant's real empirical schedule & scrub mask
# Assumes `sub01` was loaded via read_fmriprep_subject() in Step 0
tr   <- sub01$tr
cand <- hrf_library(tr = tr, preset = "medusa")
evs  <- split(sub01$events, sub01$events$run)
vrows <- lapply(sub01$confounds$runs, `[[`, "valid_rows")

sim_one_subject <- function(beta_true = 0.40, noise_sd = 0.35, rho = 0.50) {
  parcels <- setNames(rep(c("Active_ROI", "Null_ROI"), each = 6L), paste0("v", 1:12))
  h_act   <- cand[, sample(ncol(cand), 1L)]   # random physiological HRF draw
  h_null  <- cand[, sample(ncol(cand), 1L)]
  bold_sim <- cov_sim <- list()

  for (r in names(evs)) {
    n_t <- nrow(sub01$bold[[r]])
    ev  <- evs[[r]]
    t_idx <- which(ev$condition == "feedback")
    x_mod <- as.numeric(scale(rnorm(length(t_idx))))

    # Forward neural impulse series on the real empirical timestamps
    s_act <- s_null <- numeric(n_t)
    grid_t <- (0:(n_t - 1L)) * tr
    for (j in seq_along(t_idx)) {
      imp <- pmax(0, 1 - abs(grid_t / tr - ev$onset[t_idx[j]] / tr))
      s_act  <- s_act  + imp * (1.0 + beta_true * x_mod[j])
      s_null <- s_null + imp * 1.0            # evoked response, zero modulator slope
    }
    y_act  <- as.numeric(stats::convolve(s_act,  rev(h_act),  type = "open"))[seq_len(n_t)]
    y_null <- as.numeric(stats::convolve(s_null, rev(h_null), type = "open"))[seq_len(n_t)]

    ar_draw <- function() as.numeric(stats::arima.sim(list(ar = rho), n = n_t, sd = noise_sd * sqrt(1 - rho^2)))
    Y <- cbind(
      replicate(6L, 100 + y_act  + ar_draw()),
      replicate(6L, 100 + y_null + ar_draw())
    )
    colnames(Y) <- names(parcels)
    bold_sim[[r]] <- Y
    cov_sim[[r]]  <- data.frame(x_within = x_mod)
  }

  hf <- estimate_crossrun_hrf(bold_sim, evs, tr = tr, kernel_grid = cand,
                              valid_rows = vrows, spatial_groups = parcels, pooling = "parcel")
  dc <- deconvolve_crossrun_hrf(bold_sim, hf, scaling = "noise_sd", penalty = "sobolev")
  decon_epoch_regression(dc, cov_sim, evs, target_condition = "feedback",
                         lags = 0, parcel_groups = parcels, restore_scale = TRUE, return_panel = TRUE)
}

Looping sim_one_subject() across your cohort’s sub01..subN schedules and feeding the resulting panels into mixed_by() (or decon_connectivity_repair()) gives an exact, pre-data answer to whether your task jitter, run count, and motion censoring support unbiased slope recovery and nominal 5% false-positive control in Null_ROI.
