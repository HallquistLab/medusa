Relationship to the medusa R Package

This Quarto book lives in the book/ directory of the standalone medusa R package (0.1.0, excluded from CRAN/tarball builds via .Rbuildignore). Every simulation, figure, and diagnostic table in the active chapters was executed directly against library(medusa)—incorporating the complete modern pipeline architecture:

Pipeline component Core medusa functions Key methodological features
Step 0 · Task design & BIDS/fMRIPrep ingestion read_fmriprep_subject(), read_bids_events(), read_fmriprep_confounds(), read_fmriprep_aroma(), apply_aroma(), read_nifti_ts() Multi-run & inter-phase jitter feasibility benchmarks, direct 4D NIfTI ↔︎ T × V matrix extraction with pre-flight geometry checks, BIDS/fMRIPrep/BrainGnomes ingestion with clock-preserving valid_rows, frame-level $variance_confounds extraction (FD, DVARS, RVT), non-aggressive ICA-AROMA partial regression, explicit missed_feedback nuisance event retention, and event_index-keyed trial joins.
Step 1 · Spatial Graph, Cross-Run HRF & AR(\(p\)) noise build_spatial_graph(), hrf_library(), estimate_crossrun_hrf() Zero-phase respiratory motion filtering (motion_bandstop_bpm / motion_lowpass_hz), 3D physiological HRF manifold (preset = "medusa"), modulator-aware (hrf_modulators) and Empirical-Bayes fractional-ridge trial HRF scoring (amplitude_model = "auto" / "trial_ridge", low-rank Gram pairwise LR \(F\)-test), SNR/breadth-adaptive canonical de-shrinking, training-only out-of-sample parcel (t_{V-1}-to-\(Z\)) and edge-preserving cortical-sheet pooling (pooling = "graph", local sub-grid cones), GLMdenoise-style cross-validated background noise-pool PCs (noise_pcs = "auto"), and 2-pass target-excluding REML AR(\(p\)) noise refit.
Step 2 · Event-informed continuous deconvolution deconvolve_crossrun_hrf(), diagnose_crossrun_recovery(), write_nifti_ts(), deconvolve_reglin(), deconvolve_nlreg() Clock-aligned < 1/128 Hz DCT drift, confound, and cross-validated noise_pcs pre-projection (nuisance_mode = "preproject", highpass = 128) prior to \(|H(\omega)|^{-1}\) amplification & GCV, continuous neural source recovery with monotone SNR-stratified lambda tuning (lambda_mode = "auto", PAVA), whole-brain selected_adjusted_partial_r2-screened task-guarded rwls = "auto" glitch downweighting, outlier-trimmed GLS marginal "noise_sd" scaling, bold-free Step 2 \(\to\) Step 3 bold_obs (\(\le 16{,}384\) voxels) / whitened_sketch (\(> 16{,}384\) voxels) caching, explicit hrf_inverse_operator() strata, and 3D/4D NIfTI export (deconvolve_nlreg() retained as blind Bush & Cisler, 2013 comparator).
Step 3 · Trial-epoch readout, alignment & demixing decon_epoch_regression(), align_medusa_ts(), evt_align_decon_files() Local time-averaging (kernel quadrature) onto peri-event lag grids, GCV-stabilized joint (T, O) collateral non-target removal (demix_other_events, other_event_model = "auto"), post-subtraction S_clean_tau duration gain calibration ("rate" vs. "integral"), uniform multi-lag target demixing (demix_target_trials), within-trial lag demixing (demix_within_trial), edge-preserving neighborhood trial-variance shrinkage (tau2_shrinkage = "graph_eb"), exact error propagation (se_demixed), and descriptive peri-event alignment (align_medusa_ts()).
Step 4 · Parcel panels, POET CovReg & cohort weights decon_epoch_regression(..., parcel_groups = ...), aggregate_decon_panel() Multi-stratum inverse-variance parcel pooling, subspace-debiased Adaptive-POET + multi-lag Toeplitz & LTZ-gated dynamic covariance regression (shared_error_method = "poet_covreg", variance_confounds, Step-2 rwls frame_weights propagation, \(>512\)-unit lowrank_voxel mode), Block-PAF list-columns (shared_noise_vec, lag_noise_vec, trial_cor_vec) with pipe-delimited CSV/.csv.gz round-trip restoration, post-hoc voxel-to-parcel aggregation (aggregate_decon_panel()), precision_weight & precision_weight_cohort, and paired within-run trial decorrelation (whiten_panel, ZCA).
Step 5 · Group & trajectory inference mixed_by(), medusa_multilag_infer(), backproject_medusa() Cohort-weighted split-wise REML mixed models (lmerTest, supporting disk-backed Parquet/.rds/CSV streaming and split_filter pushdown), joint multi-lag trajectories with available-case pooling, conditioned spectral cross-lag deblurring (alpha1 = 0.05, alpha0_sq = 0.020), uncertainty-aware penalized splines (Marra–Wood), finite-sample covariance draws (studentized Wishart) for Max-|T| / 1D TFCE / omnibus tests, "unsmoothed" window contrasts, and NIfTI map backprojection.
Step 6 · Trial connectivity & PPI decon_connectivity_repair(), medusa_fit_mmom(), medusa_between_subject_repair() Within-trial predictor disattenuation with conditioning protection (M-MOMS), joint multi-lag partialed directed EIV connectivity (multilag_control = TRUE, control_seed_lags), stationary & dynamic cross-parcel shared_error = "auto" subtraction (including on-the-fly dynamic modulator evaluation when Step 3 ran marginally with covariates = NULL), exact residualized-seed covariance projection, single-subject (\(N=1\)) & subject-level cross-trial sandwich SEs + Satterthwaite df (crosstrial_se = TRUE), and finite-sample random-effects \(t\)-interval pooling (HKSJ).

(Under the hood, computationally intensive 3D/4D NIfTI streaming, cortical-sheet graph filters, batched Cholesky deconvolution solves, and peri-event alignment run in compiled Rcpp/RcppArmadillo kernels while exposing clean R S3 objects.)

For NIfTI matrix and file-backed workflows (read_nifti_ts(), write_nifti_ts(), build_spatial_graph(), align_medusa_ts(), voxelwise_deconvolution(), and evt_align_decon_files()), see the package vignettes (vignettes/medusa-workflows.Rmd and vignettes/medusa-docs.md) and function reference (?read_nifti_ts, ?build_spatial_graph, ?estimate_crossrun_hrf, ?deconvolve_crossrun_hrf, ?align_medusa_ts, ?decon_epoch_regression, ?medusa_multilag_infer, ?decon_connectivity_repair).

Reproducing All Simulations, Figures, and the Book

With medusa and its plotting/reporting dependencies (ggplot2, data.table, lmerTest, knitr, rmarkdown; plus ggbrain, patchwork, and RNifti when regenerating volumetric brain-map figures) installed in R, render the book from book/:

quarto render

Because quarto render reads the saved .rds and .csv outputs generated by each chapter’s standalone scripts, rendering completes in seconds. To regenerate every simulation, diagnostic table, and figure from scratch against the installed medusa package, run the chapter scripts below from book/:

Show full simulation and figure regeneration commands 
# Conceptual forward-model, end-to-end dataflow schematic, & GLM / FIR / LSS / MEDuSA benchmark
Rscript assets/forward-model.R
Rscript assets/pipeline-dataflow.R
Rscript assets/compare_glm_fir_lss_medusa.R

# End-to-end worked example & M-MOM covariance verification
(cd worked && Rscript run.R && Rscript mmom-check.R && Rscript checkpoints.R)

# Step 0: Experimental design benchmarks & BIDS/fMRIPrep subject ingestion
(cd medusa_step0_design_bids && Rscript simulate_step0.R && Rscript figures_step0.R)

# Step 1: Cross-run HRF & AR(p) noise + Woolrich noise review
(cd medusa_step1_hrf_noise && Rscript simulate_step1.R && Rscript figures_step1.R)
(cd medusa_step1_hrf_noise/woolrich_review && Rscript compare_noise.R && Rscript variance_check.R && Rscript plot_comparison.R)

# Step 2: Event-informed continuous deconvolution (including blind vs. event-informed benchmark)
(cd medusa_step2_deconvolution && Rscript simulate_step2.R && Rscript figures_step2.R)

# Step 3: Peri-event epoch readout & demixing
(cd medusa_step3_epochs && Rscript simulate_step3.R && Rscript figures_step3.R)

# Step 4: Parcel aggregation, shared noise loadings, & cohort precision weights
(cd medusa_step4_parcel_panels && Rscript simulate_step4.R && Rscript figures_step4.R)

# Step 5: Split-wise mixed models & joint multi-lag trajectory inference
(cd medusa_step5_group_models && Rscript simulate_step5.R && Rscript figures_step5.R && Rscript simulate_pr62.R && Rscript figures_pr62.R)

# Multi-lag trajectory empirical calibration (180 replications x 2 regimes)
(cd medusa_multilag_calibration && Rscript simulate.R && Rscript figures.R)

# Step 6: Trial-level connectivity, M-MOMS, & PPI sensitivity
(cd medusa_step6_connectivity && Rscript simulate.R && Rscript figures.R)
(cd medusa_connectivity_inference && Rscript prepare_figures.R)

# Volumetric spatial & parcel pooling benchmark + ggbrain maps
(cd medusa_spatial_parcel_pooling && Rscript simulate_spatial_pooling.R && Rscript figures_spatial_pooling.R)

# Visual QC & troubleshooting gallery across Steps 0-6
(cd medusa_qc_gallery && Rscript simulate_qc_gallery.R && Rscript figures_qc_gallery.R)

# Render full Quarto HTML book to _book/
quarto render
