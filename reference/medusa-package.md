# medusa: Multilevel Event-Related Deconvolved Signal Analysis for fMRI

Cross-run hemodynamic response estimation, regularized linear and
nonlinear BOLD deconvolution, auditable event-locked interpolation,
operator-based epoch de-mixing with observation-noise propagation,
Empirical-Bayes precision weighting, within-run ZCA whitening,
connectivity disattenuation, and split-wise multilevel modeling
('mixed_by', 'jlmer', 'meta_mixed_by') for event-related fMRI analyses.
